# Book Management Application

A Spring Boot CRUD application with a simple HTML frontend.

## Features
- Add Book
- View Books
- Update Book
- Delete Book

## Tech Stack
- Java 17
- Spring Boot
- REST APIs
- HTML, CSS, JavaScript
- Maven

## How to Run
1. Clone the repository
2. Open in IntelliJ IDEA
3. Run the Spring Boot application
4. Open browser: http://localhost:9090/
